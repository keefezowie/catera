# Polish canvas source (2026-10-30)

Source of the owner-approved canvas https://claude.ai/artifact/AYNBDXeKJc6z4CTtADEG67. Each `*.dc.html` file is one artboard: a 390-wide phone screen drawn in inline HTML and CSS. `/_blob/<id>` image URLs only resolve on the published canvas. `blobs.json` maps each id to an asset name, with the files under `packages/brand/assets/polish/`. Exception: `dapur-kosong` is `/_blob/ba5f57a66c0878faff8be22cf99ff036`.

Builders follow these artboards for structure, element order, art placement and copy. Spacing, sizing and other measurements come from the expo-native-ui and design-taste-frontend skills (expo-native-ui wins on conflict); the px values here are indicative only. The only intended deviations are the rulings in docs/superpowers/specs/2026-10-30-polish-artwork.md.
