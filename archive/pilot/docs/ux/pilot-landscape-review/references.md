## Applied landscape patterns

1. Daily Caterer operations now use compact heading/date/context bands, adjacent delivery detail, readable status rows, visible loading during date/filter transitions, and direct frozen-production → reviewed Ready → Dispatch handoffs.
2. Customer/quota/scheduling forms use a customer-context column, independently scrolling fields/review, and persistently visible review actions. Purchase review shows the exact external reference and inclusive expiry. Quota shortages offer an explicit fully funded date repair that must be reviewed again.
3. Customer Home pairs next delivery with quota and upcoming agenda. Schedule groups deliveries by date and uses comparison radios with descriptions. Deadline reminders name the actual default meal when one is published.
4. Phone/tablet are regression checks; the scored improvement scope remains 1280×800 and 1440×900 landscape web.

Batch operations preserve eligibility, exact frozen production version, idempotency, per-record results, and explicit confirmation. Delivered remains an individual quota-consuming action. Mobbin informed composition and disclosure; catering policy determines behavior. No reference image was copied into the app.
